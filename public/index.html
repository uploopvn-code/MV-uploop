    ChatGPT (extension) · tạo ảnh
    
          
    
            Tạo ảnh bằng phiên ChatGPT của bạn qua extension trình duyệt (thư mục
            extension/, xem README để cài). Dán token dưới đây vào popup extension.
          
    
          
          
    
            
          
    
          
    
            Trong popup extension: dán http://127.0.0.1:7788 + token →
            Kiểm tra kết nối (cửa sổ nào cũng được — extension tự tìm các cửa sổ còn lại) → đăng
            nhập ChatGPT → đặt số luồng → Bật worker. Muốn cả project dùng ChatGPT: đặt "Nguồn mặc
            định · Tạo ảnh = ChatGPT (extension)" ở trên.
          
    
        
    
        
    
          
    Google Vids (extension) · tạo video
    
          
    
            Tạo video bằng phiên Google của bạn qua chính extension trên (cùng một worker token).
            Dùng chung token ở ô trên — không cần token riêng.
          
    
          
    
            Trong popup extension: đăng nhập Google →
            mở sẵn một tài liệu Google Vids (docs.google.com/videos) và để tab đó
            mở → Bật worker Google Vids (bật/tắt riêng, chạy song song với worker
            ChatGPT). Đặt node video dùng "Google Vids (extension)", hoặc đặt "Nguồn mặc định · Tạo
            video = Google Vids (extension)" ở trên. Extension tự điền prompt, chọn 1080p, bấm Tạo
            và tải video về node. Prompt chỉ cần chữ — ảnh keyframe/ingredient là tùy chọn.
          
    
        
    
        
    
          
    Muse chat (extension) · tạo ảnh & video
    
          
    
            Tạo ảnh hoặc video qua web chat muse.ai bằng phiên đăng nhập của bạn — cùng extension và
            cùng worker token ở ô trên. Mỗi job mở một tab riêng rồi đóng.
          
    
          
    
            Trong popup extension: đăng nhập muse.ai → Bật
            worker Muse chat → đặt node ảnh/video dùng "Muse chat (extension)",
            hoặc đặt nguồn mặc định tương ứng ở trên. Ảnh được gắn vào node ảnh; video Muse thường
            khoảng 10 giây.
