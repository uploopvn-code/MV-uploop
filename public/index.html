Đạo diễn AI · từ ý tưởng đến sơ đồ

Bốn bước tuần tự: ý tưởng → kịch bản · chọn kiểu blueprint · lên blueprint · dựng sơ đồ. Mỗi bước xem và sửa trước khi đi tiếp; bật "Tự động hoàn toàn" ở bước 1 để chạy liền cả bốn bước.

1 Ý tưởng → Kịch bản

Nhập ý tưởng / logline / lời; Đạo diễn AI viết thành kịch bản để bạn duyệt. Chạy qua extension ChatGPT web (không cần API key — dùng phiên ChatGPT bạn đang đăng nhập) hoặc bằng API key (OpenAI-compatible).

Thời lượng MV được phân tích theo bài hát (đọc từ file mp3), dùng để chia phân cảnh ở bước sau.

Hoặc dùng API key (OpenAI-compatible) — bấm để cấu hình

2 Chọn master prompt (kiểu blueprint)

Master prompt quyết định blueprint ra kiểu nào. Chọn một mẫu (MV, Drama ngắn, Phim drama dài…) là áp dụng ngay cho project. Có thể xem/sửa chi tiết, hoặc sửa xong ⭐ Lưu thành mẫu để tái dùng cho project khác.

Xem / sửa nội dung master prompt

3 Lên Blueprint

Từ kịch bản (bước 1) + master prompt (bước 2), Đạo diễn AI sinh khối JSON blueprint — bạn xem/sửa ở ô bên dưới. Hoặc tự dán JSON, hay chọn file (phim dài: cả bible.json và seq-XX.json cùng lúc). Nhận cả blueprint nhạc lẫn phim/drama VEO (nhân vật, trang phục, bối cảnh, máy quay, style, cụm đối thoại…).

4 Dựng sơ đồ

Dựng sơ đồ sẽ thay toàn bộ node của project đang mở — nên tạo một Project mới cho mỗi phân đoạn/bài hát. Ảnh nhân vật / bối cảnh / trang phục cùng key đã render ở project khác của cùng phim (cùng film.title) được tự lấy lại; chỉ node mới phải render.

Hai bảng kê chạy song song trên cùng một dòng thời gian: làn A phủ kín bài, làn B là từng câu hát nhép.

ChatGPT (extension) · tạo ảnh

Tạo ảnh bằng phiên ChatGPT của bạn qua extension trình duyệt (thư mục extension/, xem README để cài). Dán token dưới đây vào popup extension.

Trong popup extension: dán http://127.0.0.1:7788 + token → Kiểm tra kết nối (cửa sổ nào cũng được — extension tự tìm các cửa sổ còn lại) → đăng nhập ChatGPT → đặt số luồng → Bật worker. Muốn cả project dùng ChatGPT: đặt "Nguồn mặc định · Tạo ảnh = ChatGPT (extension)" ở trên.

Google Vids (extension) · tạo video

Tạo video bằng phiên Google của bạn qua chính extension trên (cùng một worker token). Dùng chung token ở ô trên — không cần token riêng.

Trong popup extension: đăng nhập Google → mở sẵn một tài liệu Google Vids (docs.google.com/videos) và để tab đó mở → Bật worker Google Vids (bật/tắt riêng, chạy song song với worker ChatGPT). Đặt node video dùng "Google Vids (extension)", hoặc đặt "Nguồn mặc định · Tạo video = Google Vids (extension)" ở trên. Extension tự điền prompt, chọn 1080p, bấm Tạo và tải video về node. Prompt chỉ cần chữ — ảnh keyframe/ingredient là tùy chọn.

Muse chat (extension) · tạo ảnh & video

Tạo ảnh hoặc video qua web chat muse.ai bằng phiên đăng nhập của bạn — cùng extension và cùng worker token ở ô trên. Mỗi job mở một tab riêng rồi đóng.

Trong popup extension: đăng nhập muse.ai → Bật worker Muse chat → đặt node ảnh/video dùng "Muse chat (extension)", hoặc đặt nguồn mặc định tương ứng ở trên. Ảnh được gắn vào node ảnh; video Muse thường khoảng 10 giây.

Orbit Hub

192.168.100.5:8080 ↗

Đang kiểm tra…

Mật khẩu chỉ dùng để đăng nhập Hub. Phiên đăng nhập giữ trong bộ nhớ máy này.

Sau khi đăng nhập, mở từng node → Cài đặt Orbit để chọn kịch bản và nick. Có thể chọn riêng cho ảnh và video.

Dành cho người nối kịch bản

API: http://127.0.0.1:7788

Worker nhận job qua POST /api/worker/claim, cập nhật heartbeat và trả file qua POST /api/worker/complete. Có sẵn cầu nối worker-bridge.mjs trong thư mục ứng dụng.

Kịch bản dùng phiên trình duyệt riêng do bạn đăng nhập. Khi gặp CAPTCHA hoặc bước cần xác nhận, worker dừng để bạn xử lý.
