Đạo diễn · dựng sơ đồ tự động

Master prompt sinh ra toàn bộ asset (ca sĩ, nhạc công, sân khấu), style, cỡ máy và storyboard; công cụ tự tạo node và nối dây. Bạn chỉ việc chạy ảnh/video hoặc sửa prompt.

1. Master prompt

Chép và dán vào ChatGPT/Claude kèm bài hát (hoặc dùng mục 3 để tự động). Model phải trả về khối JSON blueprint theo mẫu ở cuối prompt. Bạn có thể sửa và lưu riêng cho project này.

2. Dán blueprint (JSON) rồi dựng

Dán khối JSON kết quả vào đây. Nhận cả blueprint nhạc và blueprint phim/drama Google VEO (từ skill drama-veo-blueprint): tự nhận nhân vật, bối cảnh, đạo cụ và nối hình tham chiếu vào từng shot. Dựng sơ đồ sẽ thay toàn bộ node của project đang mở — nên tạo một Project mới cho mỗi phim/bài hát.

Phim dài: chọn cả bible.json và seq-XX.json cùng lúc — tool tự gộp nhân vật/bối cảnh từ bible với các shot của phân đoạn.

3. Tự động qua API (tuỳ chọn)

Nhập API key một endpoint tương thích OpenAI (OpenAI, hoặc gateway của bạn). Bấm chạy là công cụ tự gọi master prompt rồi dựng sơ đồ. Thử nghiệm — nếu lỗi, dùng cách dán tay ở mục 2.

Mật khẩu chỉ dùng để đăng nhập Hub. Phiên đăng nhập giữ trong bộ nhớ máy này.

Sau khi đăng nhập, mở từng node → Cài đặt Orbit để chọn kịch bản và nick. Có thể chọn riêng cho ảnh và video.

Dành cho người nối kịch bản

API: http://127.0.0.1:7788

Worker nhận job qua POST /api/worker/claim, cập nhật heartbeat và trả file qua POST /api/worker/complete. Có sẵn cầu nối worker-bridge.mjs trong thư mục ứng dụng.

Kịch bản dùng phiên trình duyệt riêng do bạn đăng nhập. Khi gặp CAPTCHA hoặc bước cần xác nhận, worker dừng để bạn xử lý.
